# الواجهة القديمة — مواصفة بصرية

الهدف: إحساس PojavLauncher في أول إصداراته: بسيط، داكن، بلا زجاج ولا blur،
زر واحد أخضر، وأزرار تبدو مضغوطة/بارزة (bevel) مثل واجهات 2013.

## 1. الألوان

| الاستخدام | القيمة |
|---|---|
| خلفية النافذة | `#121212` |
| لوحة | `#1F1F1F` |
| صف قائمة زوجي / فردي | `#242424` / `#1D1D1D` |
| صف مختار | `#2D5A22` |
| حدود الصف المختار | `#4B8F38` |
| زر عادي | `#343434` |
| زر أساسي (Play) | `#3F8F2E` |
| نص أساسي | `#F2F2F2` |
| نص ثانوي | `#8A8A8A` |
| عناوين صغيرة | `#9A9A9A` |
| أخضر معلومات | `#8FBF7F` |
| مؤشر مثبّت | `#5DC244` |
| مؤشر غير مثبّت | `#5A3A2A` |

ممنوع: تدرجات زجاجية، ظلال ناعمة كبيرة، ألوان بنفسجية، أيقونات Material.
مسموح: حدود 1px سوداء + خط إضاءة 2px أعلى الزر + خط ظل 2px أسفله.

## 2. الخطوط

- عائلة واحدة: `monospace` (على أندرويد تتحوّل لـ monospace الافتراضي).
- العناوين: 19–20px، وزن 800، أحرف كبيرة.
- النص: 10–12px.
- الأزرار: 13px، وزن 700، أحرف كبيرة.
- كل النصوص اللاتينية UPPERCASE، والنص العربي يبقى كما هو.

## 3. التركيب (420×820 منطقي)

```
┌───────────────────────────────────────────┐
│ [RC] RUSTCRAFT              NOT SIGNED IN │ 52px
│      JAVA EDITION LAUNCHER                │
├───────────────────────────────────────────┤
│ | NEWS                                    │
│ Java Edition on your phone...             │ 92px
│ Tip: 512-1024 MB heap...                  │
├───────────────────────────────────────────┤
│ VERSION                        tap to sel │ 16px
├───────────────────────────────────────────┤
│ ■ 1.8.9                            legacy │
│ ■ 1.20.1                          release │ 44px/صف
│ ■ 1.21.1                          release │ (ListView)
├───────────────────────────────────────────┤
│ >  PLAY                                   │ 58px
│ Ready.                                    │
├───────────────────────────────────────────┤
│ HOME  INSTANCES  REFRESH  SETTINGS        │ 34px
└───────────────────────────────────────────┘
```

- الهوامش 12px، المسافات 10px.
- الشعار مربع 46×46 أخضر بحد أسود ونص `RC`.
- زر الحساب بعرض 132px وارتفاع 38px (أصغر من أزرار البطاقات).
- قائمة النسخ تتمدد (`vertical-stretch`) وتُمرَّر.
- شريط الحالة سطر واحد رمادي 10px تحت Play، يشرح آخر إجراء.

## 4. سلوك العناصر

| العنصر | السلوك |
|---|---|
| صف نسخة | يحدّد النسخة فقط؛ لا يبدأ اللعب |
| Play | يبدأ النسخة المحددة، ويتعطّل أثناء الإقلاع |
| الحساب | يفتح تسجيل الدخول (M4) أو يعرض الحساب الحالي |
| Refresh | يعيد قراءة `versions/` |
| Settings | شاشة الذاكرة/الـ renderer (M5) |
| Home / Instances | تنقّل (M5) |

حالات:

- `busy = true`: نص الزر `LAUNCHING...`، شفافية الأزرار الأخرى 45%.
- لا نسخ: Play معطّل، شريط الحالة يطلب تثبيت نسخة.
- فشل تشغيل: شريط الحالة يبدأ بـ `Launch failed:` + السبب المختصر.

## 5. ما الذي يجعله "قديماً" فعلاً

1. **حدود حادة**: زوايا 0px (لا `border-radius`).
2. **Bevel**: خط فاتح أعلى، خط غامق أسفل — نفس أزرار Java القديمة.
3. **قائمة بصفوف متبادلة** بدل بطاقات عائمة.
4. **معلومات تقنية على الشاشة** (نوع النسخة، سطر حالة) بدل إخفائها.
5. **أيقونة نصية** `[RC]` بدل شعار SVG.
6. **أخبار كنص عادي**، بلا صور أو carousel.

## 6. فروقات مقصودة عن Pojav القديم

- لا إعلانات ولا روابط Discord داخل الواجهة.
- إعداد الذاكرة واضح في شريط الحالة بدل قائمة مخفية.
- الواجهة كلها Rust/Slint، لذلك نفس الشكل على الكمبيوتر والهاتف (بدون
  إعادة تصميم).
- على أندرويد حجم النافذة يتمدّد لشاشة الجهاز؛ الأبعاد أعلاه مرجع تصميمي.
