# جهاز الهدف: Samsung Galaxy M33 5G

## 1. العتاد

| البند | القيمة |
|---|---|
| المعالج | Exynos 1280 (5nm، 2×A78 + 6×A55) |
| الرسوميات | **Mali-G68 MP4** |
| الرام | 6 GB أو 8 GB (النظام يرى ~5.4 / ~7.2) |
| الشاشة | 6.6" 1080×2408، 120 Hz |
| النظام | Android 14 / One UI 6 (حسب النسخة) |
| التخزين | 128 GB (عادةً) |

**الحكم:** جهاز متوسط جيد للانشر، وليس جهازاً ضعيفاً بالمعنى المخيف. المشكلة
الوحيدة الجدية هي **Mali-G68**، لأن مترجمات OpenGL على Mali أقل نضجاً من Adreno.

## 2. الإعداد الموصى به

| الإعداد | 6 GB | 8 GB |
|---|---|---|
| `-Xmx` | **1024 MB** | **1536 MB** |
| `-Xms` | 512 MB | 768 MB |
| Renderer | **gl4es** أولاً | gl4es، وجرّب ANGLE لاحقاً |
| Render distance | 8 chunks | 10 chunks |
| الدقة | 720p (scale 0.85) | 900p/1080p |
| الإصدار | **1.20.1 Fabric خفيف** | 1.20.1 / 1.21 |
| لأقصى FPS | 1.8.9 | 1.8.9 |

> `Zink` على Mali-G68 غالباً يعطي شاشة سوداء أو crash. لا تبدأ به.

هذه القيم مطبّقة في `rustcraft-core::profile::DeviceProfile` (اختبار
`samsung_m33_5g_6gb` موجود)، وتُطبع بـ:

```bash
rustcraft device
```

## 3. الأداء المتوقع (واقعي)

| النسخة | الإعداد | FPS تقريبي |
|---|---|---|
| 1.8.9 | 1024M، 8 chunks، 720p | 60–120 |
| 1.12.2 | 1024M، 6 chunks | 45–80 |
| 1.20.1 Fabric خفيف | 1024M، 6–8 chunks، بلا shaders | 30–55 |
| 1.20.1 + shaders | — | غير موصى به |

الأرقام تعتمد على الحرارة ووضع Game Booster؛ Exynos 1280 يخنق بعد 15–20 دقيقة
لعب طويل.

## 4. إعدادات سامسونج المهمة

1. **البطارية:** التطبيق ← Battery ← **Unrestricted** (وإلا One UI يقتله).
2. **Game Booster:** أضف اللانشر إلى Game Launcher، وفعّل "Priority mode" أثناء
   اللعب.
3. **إيقاف تحسين الذاكرة التلقائي** لهذا التطبيق إن ظهر الخيار.
4. **قفل الشاشة:** لا تترك اللعبة في الخلفية طويلاً؛ JVM يُقتل عند ضغط الذاكرة.
5. **التخزين:** كل نسخة + assets تستهلك 300–600 MB؛ 128 GB تكفي بسهولة لكن
   راقب النسخ القديمة.
6. **الحرارة:** لا تلعب أثناء الشحن السريع؛ الخنق يصير أقوى.

## 5. ملاحظة Android 15 / 16 KB pages

إذا حدّث الجهاز لاحقاً أو رفعت التطبيق إلى Play، استخدم **NDK r27+** وابنِ
المكتبات بـ 16 KB page alignment. هذا مطلوب تدريجياً لتطبيقات Android 15+،
ويخص `librustcraft_ui.so` و`libgl4es.so` و`libopenal.so`.

## 6. ماذا يعني هذا للمرحلة M3؟

- gl4es هو المسار الافتراضي؛ لا نضيّع وقتاً على Zink في البداية.
- 6 GB تكفي لـ 1.20.1، لذلك لا نحتاج "وضع 2 GB" في أول إصدار.
- Exynos 1280 يدعم Vulkan 1.1، لذلك ANGLE خيار احتياطي جيد لو gl4es فشل.
- الاختبار الحقيقي لازم يكون على M33 نفسه، وليس محاكي.

## 7. الخلاصة

جهازك مناسب جداً لهدف المشروع: **1.20.1 على 1024 MB heap بدون مبالغة في
الذاكرة**. لو نجح gl4es، المتوقع تجربة لعب مقبولة جداً لإصدار جوال Java.
